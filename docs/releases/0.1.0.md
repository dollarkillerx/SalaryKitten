# SalaryKitten 0.1.0

The first release: a chibi desktop pet that counts your salary in real time.

## New
- Live salary counter: monthly salary ÷ paid days ÷ working seconds, lunch unpaid, stops after work.
- Reminders when work starts, before and at lunch, when lunch ends and at the end of the day, plus a daily goal celebration.
- Five characters with 9 poses each and their own lines: 蓝色大肥鱼, 冬装大肥鱼, Claude娘, 冒牌 Claude, GPT娘.
- Drag anywhere, click to chat, details card, boss mode (hide all amounts), menu-bar amount on macOS.
- Launch at login, system notifications, automatic updates from GitHub Releases.

## Install
- **macOS** (Apple silicon and Intel, macOS 12 or later): `SalaryKitten-mac.dmg` — drag SalaryKitten to Applications. Signed and notarized.
- **Windows** (x64, Windows 10/11): `SalaryKitten-win-Setup.exe`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed apps update themselves (right-click the pet → 检查更新).
