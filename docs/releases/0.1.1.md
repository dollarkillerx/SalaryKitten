# SalaryKitten 0.1.1

## New
- Currency is now a dropdown: 人民币 CNY, 美元 USD, 日元 JPY, 韩元 KRW, 欧元 EUR. Choosing JPY or KRW switches to 0 decimals. Settings from 0.1.0 carry over.

## Fixed
- The monthly salary could only be saved in steps of 100 (amounts like 2156564 showed "Enter a valid value"), and the goal could not have decimals. Any amount now works, and invalid values get a clear message in Chinese.
- With the amount hidden, zero-decimal currencies no longer show a stray ".*".
- The settings preview (日薪 / 时薪) follows the decimals setting.

## Install
- **macOS** (Apple silicon and Intel, macOS 12 or later): `SalaryKitten-mac.dmg` — drag SalaryKitten to Applications. Signed and notarized.
- **Windows** (x64, Windows 10/11): `SalaryKitten-win-Setup.exe`. Not code-signed yet: if SmartScreen appears, choose **More info → Run anyway**.

Installed apps update themselves (right-click the pet → 检查更新).
